Welcome to Text Analyzer

Text Analyzer is a Flask web application that helps you explore and understand your text. It calculates word and character counts, finds the most frequent words, and measures word variety. Your analyses are saved to MongoDB so you can view them later through the History page. The application also provides a REST API that allows analyses to be created, viewed, updated, and deleted.
