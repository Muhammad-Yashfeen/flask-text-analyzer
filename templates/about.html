About Text Analyzer

Text Analyzer is a Flask web application designed to help you explore and understand the text you provide. It calculates the total number of words and characters, finds the most frequent word, measures word variety, and displays the frequency of each word.

Analyses are stored in a MongoDB database, allowing you to view your previous analyses through the History page. The application also provides a REST API with CRUD operations, allowing analyses to be created, retrieved, updated, and deleted programmatically.
